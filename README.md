# Super Projectile Bros

A Mario-themed projectile motion calculator built with Python and Tkinter. Enter known launch and motion values to solve for the remaining variables and visualize the fireball's path.

## Requirements

- Python 3
- Tkinter (included with most standard Python installations; on some Linux distributions, install the `python3-tk` package)

No third-party Python packages are required.

## Run

```powershell
python "Mario Fireball Physics.py"
```

On Windows, you can also launch the script by opening it with Python.
